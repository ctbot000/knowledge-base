# practices: simulation and game design

- [A cooldown that elapses while its precondition is false fires the instant the precondition becomes true](cooldown-fires-on-precondition.md) — The agent acts on the first tick of acquiring the thing, so the interval paces nothing; symptoms land in physics, not in the timer. `simulation`, `game-design`, `timers`
- [A simulation that restores an identical state after each event replays the same episode, whatever the seed](deterministic-reset-replays-the-episode.md) — "The seed changes nothing" points at the generator; the repetition is in the reset upstream of it. `simulation`, `testing`, `randomness`
- [A no-guess puzzle board is found by rejection sampling against a solver that only makes the player's deductions](no-guess-puzzle-generation.md) — Keep a random board only if a deliberately weak solver clears it; cheap enough to draw on demand, but acceptance collapses as density rises. `algorithms`, `puzzles`, `game-design`
- [A tug-of-war skill meter with no clock is always won by the patient player](skill-meter-needs-escalation.md) — Constant gain-vs-drain rates make skill decide the length, not the outcome; escalate the drain instead of adding a timer. `game-design`, `simulation`, `balance`
- [A moving target that outruns the thing chasing it fails a perfect player, not a bad one](tracking-target-vs-slew-rate.md) — Peak target speed above the controlled variable's slew rate makes a pursuit task unreachable; it reads as brutal tuning, so assert the ratio. `game-design`, `control`, `balance`
- [Comparing two agent configurations needs paired seeds, or the noise floor swallows the effect](paired-seeds-to-compare-agents.md) — Per-game variance buries a ~0.1 effect under a ~1.2 standard error; swapping arms across seats on the same seed cut it 30x. `simulation`, `testing`, `benchmarking`
- [Simulated player error must be sampled per decision, not per tick](simulated-error-is-per-decision.md) — A per-tick miss chance is an 8ms jitter, not a handicap; survival stays flat and a punishing game reads as trivial. `game-design`, `simulation`, `testing`
- [An affine per-unit reward barely separates skill levels; a compounding one does](multiplicative-bonus-separates-skill.md) — Perfect and good play pay within 12% of each other, so run length stops reporting skill; a streak multiplier doubled the gap. `game-design`, `balance`, `simulation`
- [A level solver guided by straight-line distance reports maze levels as impossible](level-validation-needs-a-geodesic-heuristic.md) — Euclidean ranking never leaves a spiral's outer arm; rank on a flood-filled distance field, and check reachability and completability separately. `game-design`, `level-design`, `testing`
- [Where power comes from the player's motion, an interception AI that arrives early and stops is useless](interception-ai-must-arrive-moving.md) — A perfectly positioned stationary body returns less than it received, and the rally is lost three touches later, so the symptom points away from the movement policy. `game-design`, `ai`, `simulation`
- [A boundary clamp applied during integration must run again after collision resolution](boundary-clamp-runs-after-collision.md) — Collision resolution pushes a body straight through the wall the clamp just enforced; both pieces of code are correct and the order is not. `game-design`, `collision`, `simulation`
- [A capsule end that stops flush with the wall it joins leaves a notch that traps a body for good](capsule-junction-stubs-are-traps.md) — Every individual resolution is correct; sweep release positions across the whole world to find the shelf. `game-design`, `collision`, `geometry`
- [Scaling tangential velocity by a fixed factor per contact bleeds a rolling body to a stop](friction-must-scale-with-normal-impulse.md) — A resting contact is re-resolved every substep, so flat damping compounds; cap the tangential impulse by the normal one. `simulation`, `physics`, `game-design`
- [Two contact points sharing a feature id warm-start from the same impulse, and a resting stack leans](duplicate-contact-ids-break-warm-starting.md) — Clipping can give both manifold points the same originating edge; the error is signed, so it integrates into a slow lean and more solver iterations do not help. `simulation`, `physics`, `collision`
- [A rigid constraint solved with a Baumgarte bias diverges in a network with loops, and more iterations makes it worse](rigid-constraint-diverges-in-a-loop.md) — Stable alone and in a chain; in a cloth grid it reaches a thousand times the mesh's own weight. Model "rigid" as a very stiff implicit spring instead. `simulation`, `physics`, `numerics`
- [Restitution measured at the bottom of a discrete overlap returns more energy than went in](restitution-measured-below-the-surface.md) — The body accelerates over the overshoot and the position pass hands that depth back as height, so an elastic ball climbs; halving the timestep only halves the gain. `simulation`, `physics`, `numerics`
- [In a board of bouncing obstacles the random walk's step size is set by the fall between rows, not by the obstacle spacing](ballistic-random-walk-step-is-the-drop.md) — A Galton board goes bimodal against both outer walls, and no amount of restitution, friction or ball-size tuning moves it. `simulation`, `physics`, `game-design`
- [An explicit damper between two inertias is stable on their reduced inertia, and a gear ratio shrinks it by the ratio squared](damper-stability-follows-reduced-inertia.md) — `c*dt/I_red < 2` is the threshold; the same coupling is fine in a 3:1 gear and diverges in ten steps at 13.5:1, and it reads as a friction or contact bug. `simulation`, `physics`, `numerics`
- [A retirement sweep placed after an activity guard stops running exactly when there is nothing happening](retirement-sweep-behind-an-activity-guard.md) — Expired decals and particles persist for the whole idle period, which is when they are being looked at; retire before the early return. `simulation`, `state`, `debugging`
- [A feedback flash retriggered faster than it decays is a constant state, not a flash](feedback-flash-saturates.md) — Under sustained fire a hit-flash branch is permanently on, so the artwork underneath is never seen and the cue stops carrying information. `game-design`, `ui`, `animation`
- [A removal puzzle is dealt by taking a finished board apart, and the order that does it is the solution](removal-puzzle-dealt-by-unbuilding.md) — Assign pieces at removal time and the deal is solvable by construction, with a certificate to replay in the tests; no solver needed. `procedural-generation`, `puzzles`, `game-design`
- [An obstacle that forces one input must fit inside the band where only that input works](forced-input-obstacle-fits-the-band.md) — The floor is the gap between standing and ducking hitboxes; the ceiling is every chained verb, so a barrier above a single jump is still beaten by a double one. `game-design`, `collision`, `level-design`
- [A balance change that does not move the outcome means the dominant term is elsewhere](balance-knob-with-no-effect.md) — an inert tuning knob is a fact about the model; attribute the resource by cause before changing the number again. `game-design`, `balance`, `simulation`
- [A reflecting boundary turns a projectile game's overshoot into a second attempt at the target](reflecting-boundary-rescues-overshoot.md) — A ceiling above the target makes full power always score; the tell is a scoring window whose upper edge equals the input cap. `game-design`, `collision`, `balance`
- [A centre-aimed grid action deadlocks for an entity narrower than a cell](centre-aimed-action-misses-the-support.md) — Collision uses the whole footprint but the action uses one ray, so a straddling entity drills at the empty tile beside the one holding it up. `game-design`, `collision`, `simulation`
- [An extraction economy must be net-positive with the starting loadout](extraction-economy-must-pay-at-tier-zero.md) — A trip that costs more than it earns reads as a stuck agent, not as a price; measure yield along the path travelled, not map density. `game-design`, `balance`, `simulation`
- [A perfectly regular packing passes an impulse straight through instead of scattering](perfect-packing-transmits-impulse.md) — Sequential pair collisions on an exact lattice act as a Newton's cradle: one body leaves fast, the rest sit still, and every collision is individually correct. `simulation`, `physics`, `game-design`
- [A steeper entry angle widens the target, so the best shot is the one that leaves the frame](steep-entry-widens-the-target.md) — Effective opening scales with the entry angle's sine, so the widest-window trajectory is also the tallest; measure apexes, not just makes. `game-design`, `balance`, `camera`
- [In a chained-reflection aiming problem, most solutions are knife-edge, so rank candidates by tolerance rather than by success](rank-solutions-by-tolerance.md) — Median scoring window went 0.04° to 0.58° by re-ranking the same candidates; a pass/fail verdict cannot tell a robust shot from a fluke. `game-design`, `search`, `simulation`
- [A simulated player that waits on its target absorbs everything that arrives there first](bot-camping-on-target-inflates-difficulty.md) — A controller with zero injected error still making the game's own mistakes is a policy bug, and its cost gets charged to the level design. `game-design`, `simulation`, `testing`
- [A clock topped up per unit of progress escalates on its own, and states its own survivability](progress-topup-clock-escalates-monotonically.md) — Buffer `M`, top-up `k`, length `L`: survivable while pace stays under `k + M/L` of optimal, so the whole curve is one monotone sequence. `game-design`, `balance`, `simulation`
- [Sweep the action space before tuning difficulty — "hard" and "impossible" look identical from inside the game](measure-solution-density-before-tuning.md) — Brute-force the aim/power space from real positions: near-zero solution density is a physics fault no amount of search or aim assist can fix. `game-design`, `simulation`, `testing`
- [A flawless simulated player measures an opponent's survival, never its win rate](flawless-player-measures-survival.md) — A perfect controller shuts out every tier, so difficulty has to be read from rally length; win rates need a fallible controller. `game-design`, `testing`, `simulation`
- [Injected aim error does nothing until it exceeds the catcher's own tolerance](injected-error-below-tolerance-is-inert.md) — An error smaller than half the paddle plus the ball radius yields a zero miss rate, so the difficulty dial reads as tuned while rallies never end. `game-design`, `balance`, `simulation`
- [A density contrast measured by binning reports Poisson shot noise until you subtract it](binned-variance-measures-shot-noise.md) — A uniform random field alone reads 1/sqrt(mean), so the metric starts wrong and appears to depend on resolution. `statistics`, `simulation`, `instrumentation`
- [A label keyed to a proxy variable contradicts the model as soon as the parameters leave the regime it was calibrated in](proxy-derived-labels-outlive-their-regime.md) — The narration and the readout disagree on one screen, both computed correctly, and only once someone moves a control off the default. `simulation`, `ui`, `modelling`
- [Playing a multi-scale process back in log time spends the run where the process is slowest](log-scale-playback-paces-by-physics-not-interest.md) — The underlying power law sets the pacing, so the animation is correct and still spends most of itself on one unchanging image. `animation`, `visualisation`, `simulation`
- [A retention window sized for a slow observer keeps stale entities in view when it moves fast](retention-window-scales-with-observer-speed.md) — Nothing was ever freed, so entities sit somewhere they could not have travelled to and it reads as a movement bug. `simulation`, `game-design`, `performance`
- [A bang-bang controller with no deadband drifts toward the faster direction](bangbang-drifts-on-asymmetric-rates.md) — Chatter at the switching point averages the two rates, so a hold-at-a-value loop ends up pinned at one extreme. `control`, `simulation`, `testing`
- [When every simulated skill level scores the same, the fault is the bot's perception](identical-skill-profiles-mean-a-blind-bot.md) — A flawless controller dying as often as a noisy one means the injected error never reaches the outcome; the usual blind spot is a filter that drops the hazard already overlapping the agent. `game-design`, `simulation`, `testing`
- [A moving hazard must commit its path before it enters the player's reaction window](hazards-commit-before-the-reaction-window.md) — Still choosing where to be on the approach makes it unavoidable rather than hard, and halving its speed halves the warning too; lock the final track at a handover distance. `game-design`, `balance`, `simulation`
- [A minimum-spacing rule sets the output density rather than bounding it](min-gap-sets-density-not-bounds-it.md) — Greedy placement converges on `1/gap` wherever candidates are dense, so the gap replaces the source's own shape; add a rolling-window budget alongside it. `procedural-generation`, `game-design`, `algorithms`
- [A rate-limited agent must score where it will be on arrival, not the candidate position itself](score-the-predicted-position-not-the-destination.md) — It commits to gaps it cannot reach, and raising the avoidance penalty pushes harder toward the unreachable one. `game-design`, `control`, `ai`
- [A spacing rule enforced only at spawn time does not hold once the entities move](spawn-time-constraints-do-not-survive-motion.md) — Placement and movement are both correct; the constraint has no authority over the interval between them. `procedural-generation`, `game-design`, `simulation`
- [A generated-puzzle test that reads the answer key never tests the clue](puzzle-tests-must-parse-the-clue.md) — Applying `puzzle.answer` proves the lock accepts its own key; parse the answer back out of the rendered clue or an unsolvable room passes every test. `testing`, `puzzles`, `game-design`
- [A state that zeroes a recovery rate is a dead end, not a penalty](zeroed-recovery-is-a-trap-not-a-cost.md) — The run neither wins nor loses, so win rate reports nothing; floor the rate and count stalled episodes. `game-design`, `balance`, `simulation`
- [A cooldown shared by two parties drifts out of phase unless a failed attempt resets both clocks](two-party-cooldown-must-resync.md) — Each one wakes while the other is cooling, so a pair meeting every precondition never acts; it survives a single-seed test. `simulation`, `game-design`, `timers`
- [A failure state that cannot be forced means some income is uncorrelated with the thing that fails](rescue-income-must-track-the-activity.md) — A windfall gated on a lagging indicator floats a dead system above its floor for ever, and only shows up as a code path never entered. `game-design`, `balance`, `simulation`
- [A continuous payout rounded at every tick pays out nothing](per-tick-rounded-payout-floors-to-zero.md) — A per-frame share under one unit rounds to 0 every frame, so a smoother update loop is what breaks it; carry the remainder. `game-design`, `numerics`, `simulation`
- [A difficulty tier defined by an absolute threshold is not a tier](graded-tiers-need-relative-thresholds.md) — Tiers pinned to a grid collapse into each other wherever the content already sits on it; define each as a share of the full set. `game-design`, `procedural-generation`, `balance`
- [A timeline read from an absolute clock absorbs a jump by moving its epoch, not by clamping a delta](absolute-timeline-absorbs-a-jump-by-moving-its-epoch.md) — The jump is already in `clock() - epoch`; applying it fires every event in the skipped span at once, which reads as a logic bug downstream. `game-loop`, `timing`, `frontend`
- [A solvability test cannot see a trivially solvable instance](solvable-is-not-the-same-as-worth-solving.md) — A fallback or an unconstrained distractor can make the answer a single click, and a seed sweep that only asks "is it solvable" says yes fastest of all. `procedural-generation`, `puzzles`, `testing`
- [Published yawing-moment derivatives assume the yaw axis points down, so a Y-up engine frame needs every one of them negated](yaw-derivatives-flip-with-the-yaw-axis.md) — Rolling and pitching moments are unaffected and yaw damping is sign-invariant, so a half-converted table looks consistent and diverges a minute into the flight. `simulation`, `physics`, `3d`
- [A control that springs back to mid-scale can never satisfy an interlock that tests for the end of its travel](interlock-versus-spring-return.md) — The gate refuses for a position the operator cannot see or hold, so the mode can be selected and never used; make the rest position depend on whether the interlock is armed. `ui`, `control`, `safety`
- [A loop guard counted in iterations silently truncates the request it was meant to protect](iteration-capped-loop-truncates-silently.md) — The call returns normally having done part of the work, so a fast-forward that stops early reads as a model that stopped responding. `simulation`, `debugging`, `api-design`
- [A response driven only by a lagged measurement moves the wrong way at the start of a step](lagged-measurement-inverts-the-transient.md) — Both lags are individually correct and the steady state is right; only the transient inverts, and it is blamed on whatever it shows up in. `control`, `simulation`, `modelling`
- [A protection threshold read from an instantaneous measurement fires on the transient the system exists to produce](protection-threshold-needs-filtering.md) — Peak demand and the failure condition move the same signal, so the cutoff trips at full throttle on a healthy system; separate them in frequency, not by value. `control`, `monitoring`, `reliability`
- [An entity that acts on its own schedule also acts while a test is staging the scene](autonomous-actors-act-during-test-setup.md) — The action under test is counted alongside the ones the entity took by itself, so an exact-count assertion fails and a lower-bound one passes for the wrong reason. `testing`, `simulation`, `game-design`
- [A placement bot scored on total coverage stacks every unit on one spot and measures itself](marginal-coverage-scores-the-level.md) — The score does not change as units are placed, so coverage read 43% instead of 99% and the level got blamed; weight each threat point by how well it is already covered. `game-design`, `testing`, `simulation`
