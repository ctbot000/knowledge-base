# practices: web front end

- [A rendered heading contains more than its text, so a contents list built from its markup nests a link inside a link](heading-markup-carries-injected-anchors.md) — Doc themes inject an anchor into every heading after load, so copying `innerHTML` doubles the links and swallows the click; clone and strip first. `frontend`, `dom`, `static-sites`
- [A role=grid whose cells are not inside row elements is dropped from the accessibility tree](aria-grid-needs-row-elements.md) — Browsers prune the cells; the DOM still has every aria-label, so it reads as missing labels rather than invalid structure. `accessibility`, `aria`, `css`
- [A CSS class that sets fill or stroke silently wins over setAttribute](css-class-beats-presentation-attribute.md) — Presentation attributes enter the cascade at zero specificity, so a script-set colour is ignored on exactly the elements a stylesheet already styles. `svg`, `css`, `frontend`
- [An author display rule silently overrides the HTML hidden attribute](hidden-attribute-vs-display-rule.md) — `[hidden]` is only a UA stylesheet rule, so any class setting `display` keeps the element painted while `el.hidden` reads true. `css`, `html`, `dom`
- [One key press runs two steps when a bubbling handler reads state an inner handler just changed](key-event-runs-two-steps.md) — The second step is either another listener or a default action such as implicit form submission; `stopPropagation` fixes one and `preventDefault` the other, and only the latter is reachable by a dispatched event. `dom`, `events`, `keyboard`
- [An animation lifetime counted in frames never expires while rAF is throttled](animation-lifetime-in-frames.md) — A hidden tab stops delivering frames, so a `life--` counter stalls and the overlay freezes on screen; end effects on wall-clock time. `animation`, `browser`, `requestAnimationFrame`
- [UI synced only from the animation loop cannot render the state change that stopped the loop](ui-state-synced-only-in-raf.md) — A visibilitychange handler that pauses and shows its panel from the frame loop never paints it; the model reads `paused` while the DOM still says `playing`. `browser`, `requestAnimationFrame`, `ui`
- [One-time construction placed inside the rAF callback makes the first paint wait for a frame](one-time-build-inside-raf.md) — A hidden or backgrounded surface never delivers one, so the page shows its static placeholders while every handler silently takes its `if (!built) return` branch. `browser`, `requestAnimationFrame`, `frontend`
- [A default deferred to the next frame overwrites the explicit choice made before it fires](deferred-default-outlives-its-guard.md) — The guard is tested when the callback is scheduled, not when it runs, so a deep link applied in the gap is silently replaced by the queued default. `browser`, `async`, `ui`
- [Speech synthesis picks a voice by locale, not by the language of the text](speech-synthesis-voice-follows-locale.md) — English text is read by the system-locale voice unless you set `lang` and pick a voice, and `getVoices()` is empty until `voiceschanged`. `web-speech`, `i18n`, `browser`
- [A speech utterance that never starts also never ends, while speechSynthesis.speaking reads true](speech-utterance-can-fire-no-events.md) — Blocked audio fires no `start`, `end` or `error` at all, so a promise awaiting `onend` deadlocks while both health probes look healthy. `web-speech`, `browser`, `async`
- [A UI string is not speakable text — emoji get names, and a stripped operator changes the sentence](ui-strings-are-not-speakable-text.md) — Engines read 🎉 as "party popper", and `U+2212` hides in the symbol range you sweep, so "2 − 4" is spoken "2 4". `web-speech`, `unicode`, `i18n`
- [A swallowed storage write needs an in-memory copy, or the next read contradicts it](swallowed-storage-write-stale-read.md) — `try/catch` around `localStorage` hides the failure, not the consequence; re-reading the key returns the old value and the session contradicts itself. `storage`, `caching`, `error-handling`
- [A bare text node in a flex container becomes its own flex item](flex-container-wraps-bare-text-nodes.md) — It is wrapped in an anonymous flex item, so a label and its unit span land on separate rows and every item count is off by one. `css`, `flexbox`, `layout`
- [Blockification applies to a flex or grid item, not to anything inside it](blockification-stops-at-the-item.md) — The item gets a real box, but an inline wrapper inside it stays inline and collapses to 0x0, taking its absolutely positioned children with it. `css`, `layout`, `flexbox`
- [SVG has no z-index, so a later sibling silently paints over an earlier one](svg-paint-order-hides-content.md) — The covered node keeps its box, its selectors and its events, so only a human eye or a bbox sweep notices. `svg`, `graphics`, `frontend`
- [An inline SVG sizes itself from its viewBox unless both axes are definite](svg-intrinsic-size-beats-the-box.md) — A `viewBox` ratio blows up `1fr` grid tracks and beats `position:absolute` insets, so the graphic overflows and the next row paints over it. `css`, `svg`, `layout`
- [A ResizeObserver's first callback wipes whatever the canvas has already drawn](resizeobserver-first-callback-clears-the-canvas.md) — Observing fires once immediately, and assigning `canvas.width` clears the bitmap even when the value is unchanged; only a surface with no next frame shows it. `canvas`, `browser`, `frontend`
- [A grouping property silently turns transform-style preserve-3d into flat](grouping-property-flattens-preserve-3d.md) — `opacity`, `filter`, `clip-path` or a clipping `overflow` collapse 3D children into one plane while `getComputedStyle` still reports `preserve-3d`. `css`, `3d`, `transforms`
- [Electron's findInPage findNext option starts a search session, it does not step to the next match](findinpage-findnext-starts-a-session.md) — `findNext: false` on the first request is dropped silently and `found-in-page` never fires; omitting the option starts a session. `electron`, `browser`, `find-in-page`
- [A shrinkable flex item contributes its content width, not its flex-basis, to an auto-sized container](flex-basis-does-not-size-an-auto-container.md) — `flex: 0 1 190px` renders at the text's width; use `width` for a fixed preferred size. `css`, `flexbox`, `layout`
- [Overlapping translucent shapes compound per fill(), not per shape](canvas-translucent-fill-compounding.md) — One path fills the union at a flat alpha; a fill per shape stacks at every overlap, and winding is not what causes it. `canvas`, `graphics`, `frontend`
- [A stroke on a union path redraws the seams that a single fill erased](stroke-outlines-every-subpath.md) — `stroke()` outlines every subpath, including the ones buried inside the union, so a rim added to a flat-filled blob reinstates its internal edges. `canvas`, `graphics`, `frontend`
- [A layout measured while the surface is hidden is zero, and rescaling from it cannot recover](zero-measurement-poisons-derived-layout.md) — A collapsed pane returns a 0x0 box; clamp to a floor and regenerate disposable state instead of scaling noise back up. `css`, `layout`, `canvas`
- [An overlay on a letterboxed stage must size in container units, not viewport units](overlay-units-follow-the-stage.md) — `vw`/`vh` measure a box the stage does not occupy, so a phone-sized HUD swallows a fixed-aspect canvas. `css`, `layout`, `responsive`
- [A nowrap flex row inside an auto grid track overflows instead of shrinking, and min-width:0 does not help](auto-grid-track-blocks-flex-shrink.md) — The track's automatic minimum is the whole un-shrunk row, so the items are never asked to shrink; cap it with `minmax(0, 1fr)`. `css`, `grid`, `flexbox`
- [An oversized item in an auto grid track is not centred, because the track grew to fit it](auto-grid-track-defeats-centring.md) — `place-items: center` aligns inside the track, and an auto track is max-content, so the item sits flush left instead; flex centres it correctly. `css`, `grid`, `layout`
- [A flex item that grows ignores aspect-ratio, because both of its axes are then definite](aspect-ratio-loses-to-flex-grow.md) — `flex-grow` resolves the main size and `stretch` the cross size, so the declared ratio is inert and a canvas renders stretched. `css`, `flexbox`, `layout`
- [Nearest-neighbour blitting at a fractional offset seams every tile edge](fractional-blit-offset-seams.md) — `imageSmoothingEnabled = false` is nearest-neighbour, not exact; a fractional camera offset drops a row at every tile edge, and only while it moves. `canvas`, `graphics`, `frontend`
- [A node cloned into the page for an animation is still matched by the selector that produced it](animation-clones-must-leave-the-selector.md) — Each run clones the previous run's clones; they finish transparent, so it surfaces as a leak and as element counts that no longer match reality. `dom`, `animation`, `frontend`
- [A one-shot entry animation replays every time its element is recreated, so a wholesale re-render turns it into a flicker](entry-animation-replays-on-rerender.md) — Each replay is cut short by the next render, so elements sit permanently in the animation's opening frames and it reads as a CSS bug. `css`, `animation`, `frontend`
- [Filler nodes in a container break an incremental render that appends by child count](filler-nodes-break-append-by-count.md) — The padding already satisfies the length test, so later items are silently dropped and it reads as a data bug upstream. `dom`, `frontend`, `rendering`
- [A lifecycle autosave persists the placeholder state behind the menu](autosave-persists-placeholder-state.md) — beforeunload fires for the demo world under the title card, so a first-time visitor is offered "Continue" for a session they never began. `persistence`, `ui`, `browser`
- [Fitting text into a narrowing shape needs a search over wrap width, not just font size](fitting-text-to-a-shape.md) — Shrinking the font wraps the text into fewer, longer lines, so the single-variable loop bottoms out still overflowing. `css`, `typography`, `layout`
- [A hidden page's timer budget turns setTimeout into a one-second yield, but only when there is work between yields](hidden-page-timer-budget.md) — Chunked work stalls off-screen while a microbenchmark of the yield reports 0 ms; MessageChannel is not budgeted. `browser`, `performance`, `async`
- [A hidden page delivers no scroll events and no IntersectionObserver entries, so scroll-revealed content never appears](hidden-page-delivers-no-scroll-or-intersections.md) — The DOM and scroll position look right, so it reads as a broken observer config rather than a hidden page; sweep on `visibilitychange`. `browser`, `dom`, `frontend`
- [A theme-scoped element selector outranks a component's own class](theme-scoped-selector-outranks-component-class.md) — `:root[data-theme] a` beats `.btn.primary`, painting a link-button's label the colour of its own background, in one theme only. `css`, `theming`, `frontend`
- [An exception inside a self-rearming rAF callback truncates every frame without ever stopping the loop](throwing-draw-call-in-a-rearming-raf-loop.md) — Canvas throws on a negative or non-finite radius; the page stays alive and responsive while the surface silently stops being painted. `browser`, `canvas`, `requestAnimationFrame`
- [A canvas 2D context silently ignores an invalid value and keeps the previous one](canvas-ignores-invalid-values.md) — A `var()` in `ctx.font`, an incomplete shorthand or a negative `lineWidth` all no-op without throwing, so the drawing uses whatever the last successful call set. `canvas`, `graphics`, `frontend`
- [AudioContext.currentTime is the time being handed to the output, not the time being heard](audiocontext-currenttime-is-not-audible-time.md) — Visuals driven from it run `outputLatency` ahead of the sound; the offset is per-device, so it never shows on the machine it was built on. `web-audio`, `audio`, `frontend`
- [A suspended AudioContext holds currentTime still, so any clock derived from it stops](suspended-audiocontext-freezes-currenttime.md) — It keeps a plausible non-zero value instead of erroring, so everything draws while nothing moves; anchor to a wall clock or gate on `state === 'running'`. `web-audio`, `audio`, `browser`
- [Redefining grid-template-areas re-points the existing track list at different areas](grid-track-list-is-positional.md) — The sizes stay put while the areas move under them, and any row the list does not cover falls to `grid-auto-rows`; it breaks at one breakpoint only. `css`, `grid`, `layout`
- [A submit function that stores its own argument overwrites the widget state it was derived from](validator-overwrites-widget-state.md) — Indices in, symbols back out: the rejected attempt looks fine and the control only breaks the next time it is built from state, persisted corruption included. `ui`, `state`, `frontend`
- [A duck-and-restore that reads its restore level from the live node latches the ducked value](duck-restore-reads-live-value.md) — Two overlapping ducks make zero the value to restore, so the bus is muted for the rest of the session with nothing left to undo it. `web-audio`, `state`, `audio`
- [A clock that switches sources must rebase from a live reading, not from the value it last returned](clock-rebase-needs-a-live-anchor.md) — The last handed-out value is as stale as its last caller, so the handover rewinds the clock by however long the app sat idle. `clocks`, `web-audio`, `frontend`
- [An armed-tool mode that survives its own success turns every later click into a refusal](armed-mode-must-disarm-on-success.md) — The apply looked fine; the damage lands one click later as a confident sentence about the target, so the user blames the target and not the mode. `ui`, `interaction-design`, `frontend`
- [Container query units resolve against an ancestor container, never the element's own](container-units-skip-their-own-container.md) — `120cqw` on the container itself silently measures the viewport; a custom property holding one resolves where it is used, so half the geometry can be right. `css`, `layout`, `container-queries`
- [The scaffolding of a CSS 3D scene intercepts the pointer for everything inside it](preserve-3d-scaffolding-eats-the-pointer.md) — The wrappers are flat boxes at the camera plane, so they win the hit test against the very children they position; painting still looks right. `css`, `3d`, `pointer-events`
- [A responsive flex-direction flip turns every item's flex-basis from a width into a height](flex-basis-follows-the-direction-flip.md) — `flex: 1 1 150px` is 150px wide in a row and 150px tall in a column, so stacking cards in a media query gives every one a fixed height. `css`, `flexbox`, `layout`
- [A scroll container zeroes its own automatic minimum size, not its parent's](scroll-container-min-size-stops-at-itself.md) — `overflow:auto` one level below a grid item does not stop the item's `auto` minimum from blowing the track out; `min-width:0` on the item does. `css`, `grid`, `layout`
- [A grid or flex item sized with width:100% overflows by exactly its own margin](width-100-percent-ignores-the-items-margin.md) — `stretch` subtracts the item's margins and `width: 100%` does not, so one indented item alone breaks out of the track. `css`, `grid`, `layout`
- [A pointer gesture is completed by the element it started on, not by the one under the release](gesture-completion-belongs-to-its-press.md) — Listening for pointerup on window and then testing e.target discards every real click while drag keeps working, so it reads as a dead action. `dom`, `events`, `pointer-events`
- [HTMLImageElement.decode() never settles on a page that is not being painted](image-decode-waits-for-a-paint.md) — `complete` and `naturalWidth` say the image is there and the promise stays pending for ever, so an await returns nothing and throws nothing. `browser`, `dom`, `async`
- [Canvas blend modes do per-channel set arithmetic, so several soft masks fit in one RGBA upload](canvas-composites-do-channel-arithmetic.md) — `lighter` adds a region into one channel and `multiply` by `rgb(0,255,255)` subtracts it from red alone; blurred fills make the edges feather. `canvas`, `graphics`, `frontend`
- [<center> computes to text-align: -webkit-center, which tables reset](center-computes-to-webkit-center.md) — It centres block children too, and stops at a table, so implementing either half alone mis-renders every page wrapped in one. `css`, `html`, `layout`
